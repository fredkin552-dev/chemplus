# ChemPlus - Product Showcase Website

A modern ASP.NET Core MVC website for showcasing products for sale.

## Features
- Product catalog with images and descriptions
- Responsive design with Bootstrap
- Product details pages
- Category filtering

## Local Development
```bash
dotnet run
```
Visit: http://localhost:5124

## Deployment
This app is configured for easy deployment to Railway, Render, or Azure.

## Tech Stack
- ASP.NET Core MVC
- C#
- Bootstrap 5
- Entity Framework (ready for database integration)
